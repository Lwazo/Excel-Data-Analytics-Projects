# Business Sales Analysis Dashboard (Excel)

## Overview

This project is an interactive **Business Sales Analysis Dashboard built in Microsoft Excel**. It provides key insights into sales performance, profit trends, and product category distribution to support data-driven business decisions.

The dashboard transforms raw sales data into meaningful visual reports using Excel features such as Pivot Tables, Charts, and Slicers.

---

## Key Objectives

* Analyze overall sales performance
* Identify top-performing categories and segments
* Track profit and cost distribution
* Compare sales across different states
* Provide interactive filtering for better decision-making

---

## Key Insights

* Total Sales, Total Profit, and Total Cost are clearly summarized in KPI cards
* Technology and Office Supplies show strong contribution to revenue
* Consumer segment contributes significantly to overall profit
* Sales performance varies across different states, highlighting regional trends
* Sub-category analysis helps identify high and low-performing products

---

## Tools & Features Used

* Microsoft Excel
* Pivot Tables & Pivot Charts
* Slicers for interactive filtering
* Bar Charts, Line Charts, and Donut Charts
* Data Cleaning & Transformation
* KPI Dashboard Design

---

## Project Structure

* `Dashboard` → Main interactive dashboard
* `Sales_Info` → Raw cleaned dataset
* `Total Sales` → Sales calculations
* `Total Profit` → Profit analysis
* `Profit per Segment` → Segment-level insights
* `Total Cost` → Cost breakdown

---

## Business Value

This dashboard helps businesses:

* Track performance in real-time
* Make informed financial decisions
* Identify profitable segments and regions
* Optimize product and sales strategies
